## 3.1 公共几何模型

### 3.1.1 模型任务与适用范围

五个问题虽然分别涉及位置与速度、碰撞终止、最小螺距、调头路径和速度上限，但都必须先回答同一个几何问题：给定龙头前把手所在轨迹位置及当前轨迹方程，如何唯一、稳定地还原整条板凳龙的全部把手中心以及各块实体板凳的几何状态。因此，本节建立一个可复用的公共几何模型，将"轨迹—节点链—实体板凳"的还原过程封装为完整框架，供后续各问继承。

本模型的输入为：当前轨迹的参数方程 $\Gamma(q)$、龙头前把手的轨迹参数 $q_0$、各相邻把手中心距 $\{L_i\}_{i=1}^{223}$，以及板凳的长宽尺寸参数。输出为：$224$ 个把手中心 $P_0,P_1,\ldots,P_{223}$ 和 $223$ 块有向实体矩形 $R_1,R_2,\ldots,R_{223}$。完成标准包括：节点顺序沿选定轨迹分支连续递推、相邻把手中心距满足题面给定值、求交过程不跳圈、实体矩形方向与四角点可恢复。

需要明确的是，时间变量、速度递推、碰撞判定和参数优化均不在本节范围内；它们分别由后续问题在继承本节几何状态的基础上增量建立。

### 3.1.2 节点、尺寸与轨迹统一表示

**节点与编号。** 板凳龙由 $223$ 块板凳组成，共有 $224$ 个把手中心。按龙头到龙尾的方向统一编号为
\[
P_0,\ P_1,\ \ldots,\ P_{223},
\]
其中 $P_0$ 为龙头前把手，$P_{223}$ 为龙尾后把手。第 $i$ 块板凳由相邻把手 $P_{i-1}$ 与 $P_i$ 共同确定，$i=1,\ldots,223$。题面所称"第 $k$ 节龙身"与全局节点索引的映射关系在展示结果时另行说明，本节统一采用上述全局编号以避免混用。

**把手中心距。** 依据题面，龙头板长为 $3.41\,\mathrm{m}$，龙身和龙尾板长均为 $2.20\,\mathrm{m}$；孔中心距最近的板头为 $0.275\,\mathrm{m}$。由此，龙头相邻两把手中心距为
\[
L_1 = 3.41 - 2\times 0.275 = 2.86\ \mathrm{m},
\]
其余相邻把手中心距为
\[
L_i = 2.20 - 2\times 0.275 = 1.65\ \mathrm{m},\qquad i=2,\ldots,223.
\]
这里 $L_i$ 是把手中心距，不是板凳总长度；板凳总长度仅在实体矩形恢复时使用。

**轨迹统一表示。** 所有把手中心均位于当前轨迹上，采用参数方程统一记为
\[
P_i = \Gamma(q_i),\qquad i=0,1,\ldots,223,
\]
其中 $q_i$ 为节点 $P_i$ 的轨迹参数，$\Gamma(q)$ 为当前轨迹的参数方程。不同问题可代入不同的具体轨迹（例如等距螺线或分段调头曲线），但本节不展开任一分题的轨迹参数，仅要求 $\Gamma(q)$ 在其定义域内连续、可计算，并保持方向一致的分支。该表示将轨迹设计与几何还原分离，使后续问题替换轨迹时无需重新建立节点递推框架。

### 3.1.3 逐节点定长求交与连续分支选择

**建模动机。** 若将 $224$ 个节点的轨迹参数同时作为未知量，需一次性求解 $223$ 个相互耦合的非线性定长方程。由于轨迹与定长圆可能存在多个交点，全局联立不仅规模较大，而且容易收敛到节点顺序错误或跨越轨迹圈层的数学根。鉴于板凳龙本身是首尾串联的链式结构，已知前一节点 $P_{i-1}$ 后，后一节点 $P_i$ 只需同时满足"位于轨迹上"和"与前一把手距离固定"两个条件。因此采用沿龙头到龙尾逐节点递推的策略，将大规模耦合问题拆分为 $223$ 个独立的一维求根问题，每一步均可立即检验距离残差与节点顺序，失败位置亦可准确定位。

**定长约束方程。** 已知 $P_{i-1}$ 后，以该点为圆心、$L_i$ 为半径作圆；下一把手中心必须同时位于该圆与轨迹 $\Gamma(q)$ 上，故求解
\[
F_i(q) = \|\Gamma(q)-P_{i-1}\|^2 - L_i^2 = 0.
\]
求得有效根后令
\[
P_i = \Gamma(q_i).
\]
式中 $F_i(q)$ 为第 $i$ 步的定长约束函数，$q$ 为待求的轨迹参数，$P_{i-1}$ 为上一步已确定的把手中心（单位：$\mathrm{m}$），$L_i$ 为第 $i$ 段把手中心距（单位：$\mathrm{m}$），$\|\cdot\|$ 为欧氏距离。该方程将"相邻把手中心距固定"的几何约束转化为轨迹参数的一元非线性方程，是逐节点递推的核心公共关系。

**最近有效根与分支选择。** 同一个定长圆可能与轨迹的不同分支或不同圈层相交，仅满足 $F_i(q)=0$ 不能保证得到物理上的下一节点。为防止跳圈和节点交叉，在候选根中需同时满足轨迹分支方向、节点参数顺序及距离残差约束。具体地，在满足 $q>q_{i-1}$ 且沿轨迹方向连续的候选根中，选取距离 $P_{i-1}$ 最近的有效交点，即
\[
q_i = \min\{\,q > q_{i-1} : F_i(q)=0\,\},
\]
并且每一步须通过距离残差检验
\[
\bigl|\,\|P_i-P_{i-1}\| - L_i\,\bigr| \le \varepsilon_L,
\]
其中 $\varepsilon_L$ 为把手中心距残差容限。该规则保证的是几何连续性，而非碰撞安全性；碰撞判定由后续问题在实体几何基础上另行建立。

### 3.1.4 从中心链恢复实体板凳

**恢复必要性。** 把手中心链仅刻画了板凳的轴线骨架，不足以支撑后续实体几何分析。问题2、问题3中的碰撞判定需要判断的是真实板凳区域是否发生接触，而非无厚度的中心线是否相交。因此，在获得节点链 $\{P_i\}$ 后，必须进一步由相邻把手中心恢复每块板凳的轴向方向、法向方向、几何中心及有向矩形区域。

**几何构造。** 第 $i$ 块板凳的轴向单位向量由两把手中心的连线方向确定：
\[
\boldsymbol\varepsilon_i = \frac{P_i-P_{i-1}}{\|P_i-P_{i-1}\|},
\]
法向单位向量取与轴向垂直的单位向量（按右手系约定）：
\[
\boldsymbol n_i = (-\varepsilon_{iy},\ \varepsilon_{ix}),
\]
板凳中心为两把手中心的中点：
\[
C_i = \frac{P_{i-1}+P_i}{2}.
\]
设第 $i$ 块板凳的半长为 $a_i$、半宽为 $0.15\,\mathrm{m}$（板宽 $0.30\,\mathrm{m}$ 之半），则有向矩形区域定义为
\[
R_i = \{\,C_i + \alpha\boldsymbol\varepsilon_i + \beta\boldsymbol n_i : \ |\alpha|\le a_i,\ |\beta|\le 0.15\,\}.
\]
上述式中，$\boldsymbol\varepsilon_i$ 为板凳轴向单位向量（无量纲），$\boldsymbol n_i$ 为法向单位向量（无量纲），$C_i$ 为板凳中心（单位：$\mathrm{m}$），$a_i$ 为板凳半长（单位：$\mathrm{m}$），$R_i$ 为第 $i$ 块实体板凳所占的平面区域（单位：$\mathrm{m}^2$）。龙头板凳半长 $a_1=1.705\,\mathrm{m}$，其余板凳半长 $a_i=1.10\,\mathrm{m}\ (i=2,\ldots,223)$。通过该构造，相邻两个把手中心不仅确定了板凳轴线，还唯一确定了板凳中心、方向及四个角点，从而为后续碰撞分析提供了可直接使用的实体几何对象。

### 3.1.5 几何检验、局限与后续继承

**几何验收。** 公共几何模型建立后，需对以下方向进行验收：龙头初始点坐标、相邻把手中心距、节点参数顺序与单调性、最近有效根选取、实体矩形方向及四角点构造。依据交接记录，上述几何验收内容已通过 $7$ 项自动测试【待补：原始代码入口与测试原始输出复核】。本节仅按交接记录登记该验证摘要，不超出此边界宣称完整代码复核或全题精度验证。

**适用边界。** 本模型基于以下前提：板凳在二维俯视平面内视为不可伸长、不可弯曲的刚体矩形；相邻板凳通过公共把手形成理想铰链，忽略孔径和连接间隙；节点始终位于给定轨迹，并按连续、方向一致的分支递推；定长圆与轨迹的有效交点存在且可按最近有效根规则唯一选取。若轨迹不连续、曲线分支定义不清或定长圆不存在有效交点，模型应停止递推并报告失败位置，不得强行外推。

**后续继承。** 后续各问将继承本节建立的公共几何模型：问题1在该几何状态上建立弧长—时间关系与速度递推；问题2、问题3在实体矩形基础上增加碰撞判定或螺距设计；问题4以分段调头轨迹替换本节中的统一轨迹接口；问题5在问题4的固定路径几何上复用几何与速度关联。速度传递、碰撞阈值、最优螺距及调头圆弧参数等内容分别在各问中独立展开，不提前混入本节。
