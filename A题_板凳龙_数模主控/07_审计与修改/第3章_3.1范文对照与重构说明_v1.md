# 第3章3.1公共几何模型：范文对照与重构说明

## 一、参照材料与审读方法

当前工作区未发现一份单独命名为“范文”的参考论文文件，因此本次以已有手审阅稿中较成熟的论证段落作为本题写作标尺，重点参照：Q1的“本问回答什么—继承与新增—为什么这样设计—完整求解过程”链条，Q2的“实体对象为何必要—筛选判据为何分层”链条，以及Q3的“本问不做什么—新增变量是什么—为何选择该方法”链条。只迁移段落功能、因果推进和信息密度，不迁移它们的题目事实、数值结论或专属算法。

## 二、逐段差距对照

| 写作位置 | 手审阅稿的有效做法 | 当前Kimi回稿的问题 | 重构动作 |
|---|---|---|---|
| 章首总起 | 先用一句话回答本模型解决什么，再说明本问不解决什么 | 输入、输出、完成标准连续堆叠，像接口说明 | 先提出“龙头轨迹如何传递为全队几何状态”的共同问题，再用一段划定边界 |
| 节点与轨迹 | 从板凳链式连接的物理事实自然引出节点、中心距和轨迹 | 直接按“节点与编号—把手中心距—轨迹统一表示”并列定义 | 改为“链式连接决定节点关系；板长决定中心距；轨迹约束决定节点必须落在曲线上”的递进 |
| 逐节点求交 | Q1/Q2均先解释为什么不能用简单或错误方法，再给出选择 | 虽写了全局联立缺点，但真实轨迹、最近根和残差检查之间衔接断裂 | 合并为一条因果链：整体联立难且易错 → 局部圆弧会积累误差 → 真实轨迹定长求交 → 最近有效根保证物理顺序 |
| 实体恢复 | Q2先指出中心线不能代表实体，再说明矩形是碰撞对象 | 当前回稿先说“后续需要”，但没有把“中心链—实体区域”的转换说透 | 先建立“中心链只确定轴线”的限制，再说明长宽、方向和角点如何被两个相邻节点唯一确定 |
| 公式桥接 | 公式前有当前困难，公式后说明输出如何进入下一步 | 公式本身准确，但段间更像公式清单 | 每组公式只解决一个明确困难，并在公式后说明该结果如何成为下一模块输入 |
| 检验与收束 | 先说明验收对象，再说明证据边界和模型局限 | 检验、假设、后续用途平行罗列，结尾发散 | 按“几何约束是否满足 → 何时停止 → 后续继承什么”收束 |

## 三、重构后的语言原则

1. 每段先回答一个问题，再给定义或公式；不以符号表代替论证。
2. 连续公式必须有输入—输出关系：轨迹表示产生候选点，定长方程筛选下一节点，节点对产生板凳方向和区域。
3. “公共模型”只写稳定关系；速度、碰撞、螺距和调头路径只作为后续继承对象点到为止。
4. 减少“接口、调用、完成标准”等软件化表达，改用“继承、代入、恢复、判定、停止递推”等数学叙述。
