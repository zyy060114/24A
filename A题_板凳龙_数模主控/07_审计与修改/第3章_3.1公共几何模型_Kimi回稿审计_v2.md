# 第3章3.1公共几何模型：Kimi回稿审计 v2

## 总体结论

**语言与论证已基本达到可用水平，但当前版本不能直接进入正文，需先修复公式转码问题并做少量措辞校正。** 与上一版相比，本稿已经形成“共同任务—链式表示—逐节点求交—实体恢复—验收边界”的连续论证，不再像接口说明书；当前主要风险集中在数学公式被错误转义后无法正常渲染，且个别句子存在技术表述不严谨。

- 3.1仍然是一个完整的公共几何模型，没有拆成多个并列模型。
- 没有越界写入速度递推、碰撞判据、最小螺距或调头优化。
- (P_0)、(P_{223})、(L_i)、(Gamma(q))及实体板凳对象的主口径保持一致。
- 段落推进已改善：先说明共同任务，再解释为什么逐节点求交，最后从中心链过渡到实体区域。
- 7项测试被明确限定为“交接记录”，没有伪装成已完成的独立复核。

## 必须修改项

### M1：全面修复公式转码

- **定位**：全文所有公式环境及行内公式。
- **类别**：公式/格式准确性。
- **问题**：多个公式被转成了不可渲染形式，例如 `[ ... ]` 代替 `\[ ... \]`，`min{,q...`、`\left{, ...` 等结构损坏；变量下标出现 `q\_0`、`P\_{223}` 形式，不能作为正常LaTeX直接使用。
- **影响**：公式无法稳定渲染，部分集合、范数和最小值表达式的数学含义不再清晰。
- **修改**：统一恢复标准LaTeX：行内使用 `\( ... \)`，独立公式使用 `\[ ... \]`；下标使用 `q_0`、`P_{223}`；范数使用 `\|\cdot\|`；集合使用 `\left\{ ... \right\}`；最近根写为
  `\(q_i=\min\{q>q_{i-1}:F_i(q)=0\}\)`。
- **范围**：当前稿必须修复；以后所有Kimi回稿均适用。

### M2：修正“截断误差不转化为几何对象本身的改变”

- **定位**：3.1.2中“真实轨迹求交”段末句。
- **类别**：技术表述。
- **问题**：截断误差客观上仍会造成节点数值误差，“不转化为几何对象本身的改变”容易被理解为算法没有误差。
- **影响**：夸大数值求根的准确性，削弱误差边界的严谨性。
- **修改**：改为“数值求根只用于在真实轨迹上定位交点，不以局部圆弧替代待求轨迹；其离散误差应通过中心距残差和节点顺序检查控制。”
- **范围**：当前题目专属，但原则可复用。

### M3：将“实体几何分析”改为本节可支持的具体用途

- **定位**：3.1.3首段。
- **类别**：逻辑精度。
- **问题**：“后续实体几何分析”范围过宽，容易把碰撞判定提前带入本节。
- **修改**：改为“为后续需要实体边界的判定提供统一几何对象”，不直接展开碰撞。
- **范围**：当前题目专属。

### M4：统一“定长圆/圆”称谓

- **定位**：3.1.2第二段。
- **类别**：术语一致性。
- **问题**：前文使用“定长圆”，后文改为“作圆”，虽不构成数学错误，但削弱了该圆由中心距约束产生的含义。
- **修改**：统一为“以 (P_{i-1}) 为圆心、(L_i) 为半径的定长圆”。
- **范围**：可跨题复用。

## 可选优化项

- “各不相同”可改为“虽分别改变研究场景或约束条件”，更贴合五问之间的模型继承关系。
- 3.1.1末段“哪一个位置才符合板凳连接关系”较口语，可改为“哪些轨迹点同时满足连接约束”。
- 3.1.3末段可将“得到可供后续实体几何分析继承的统一对象”改为“从而为后续需要板凳实体边界的模型提供统一输入”。

## 本次写作注意事项

1. Kimi润色后必须单独进行LaTeX结构检查，不能只检查中文语句。
2. 任何涉及集合、范数、下标和最小值的公式，必须逐式确认括号、转义和定义域。
3. 技术表述应区分“在真实轨迹上建模”和“数值求根存在误差”，不得把前者写成后者没有误差。

## 长期规则候选

- Kimi回稿涉及公式时，必须同时做“语义审计”和“转码审计”：语义审计检查公式含义，转码审计检查定界符、下标、集合括号、范数和可渲染性。
