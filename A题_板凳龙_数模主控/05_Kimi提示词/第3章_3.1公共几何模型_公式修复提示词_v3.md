## 逐式硬性修复规范

1. 行内公式必须写为 `\( ... \)`，例如 `\(P_0\)`、`\(q_i\)`；不得写成 `(P\_0)`、`(q\_i)`。
2. 独立公式必须写为 `\[ ... \]`；不得写成 `[ ... ]`。
3. 下标必须写为 `_`，例如 `P_{223}`、`q_{i-1}`、`\varepsilon_L`；不得在下划线前加入反斜杠。
4. 向量范数必须使用 `\|x\|` 或 `\left\|x\right\|`，不得写为单竖线 `|x|`。
5. 集合必须使用 `\left\{ ... \right\}`；绝对值使用 `\left| ... \right|`。
6. 恢复并保持下列公式的数学含义：

\[
F_i(q)=\left\|\Gamma(q)-P_{i-1}\right\|^2-L_i^2=0,
\]

\[
q_i=\min\left\{q>q_{i-1}:F_i(q)=0\right\},
\]

\[
\left|\left\|P_i-P_{i-1}\right\|-L_i\right|\leq\varepsilon_L,
\]

\[
\boldsymbol\varepsilon_i=\frac{P_i-P_{i-1}}{\left\|P_i-P_{i-1}\right\|},
\qquad
R_i=\left\{C_i+\alpha\boldsymbol\varepsilon_i+\beta\boldsymbol n_i:
|\alpha|\leq a_i,\ |\beta|\leq0.15\right\}.
\]
