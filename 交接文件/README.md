# 数学建模交接文件

本目录就是论文手和总控使用的最终交付目录。每个问题独立成一个同级文件夹，不再设置额外的“建模手交接”中间层。

## 交付顺序

1. `00_基础几何与速度/`：公共几何模型；
2. `01_Q1_螺线位置与速度/`：问题1位置与速度；
3. `02_Q2_碰撞模型/`：问题2碰撞模型；
4. `03_Q3_最小螺距/`：问题3最小螺距；
5. `04_Q4_调头路径/`：问题4调头路径；
6. `05_Q5_最大速度/`：问题5最大允许龙头速度。

## 本轮口径

Q4、Q5采用用户指定的扩展螺距 $p=0.450342\,\mathrm{m}$。题面Q4原始螺距为1.7 m，已在Q4、Q5正文中明确区分，不能混写。

每个问题文件夹内部的 `README.md`、论文手审阅稿、`tables/`、`figures/` 和代码共同构成交付包。详细结果必须先读对应问题的论文手审阅稿。
