# Q5 正式求解验证计划

| 验证项目 | 计划方法 | 通过口径 |
|---|---|---|
| 刚杆速度约束 | 回代 ((P_i-P_{i-1})\cdot(V_i-V_{i-1})) | 最大绝对残差低于数值容差 |
| 速度上限回代 | 令 (v_{head}=2/K_{max}) 重算 | 全部速度不超过2 m/s，峰值在容差内达到2 |
| 步长收敛 | 粗、中、细三档空间步长 | 连续两档 (K_{max}) 和速度上限变化低于目标精度 |
| 连接点检查 | 对所有分段连接状态加密 | 不漏掉连接邻域峰值 |
| 小分母检查 | 排序最小递推分母并局部加密 | 无未报告近奇异状态 |
| 独立差分 | 对位置状态作中心差分 | 与解析速度向量在目标误差内一致 |
| 参数灵敏度 | 扰动Q4几何参数、求根容差和步长 | 结论无非物理跳变，并报告变化范围 |
| 直线极限 | 同向直线人工算例 | 全部 (K_i=1) |
