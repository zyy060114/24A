# 问题5：最大允许龙头速度模型接口与依赖说明

## 1. 本问到底要回答什么

在一条已经确定的调头路径上，龙头保持恒定速度运动。问题5需要确定龙头速度的最大允许值，使任意时刻、任意把手的速度大小均不超过 (2\,\mathrm{m/s})。

本目录采用用户更正后的扩展口径 (p=0.450342\,\mathrm m)。问题3给出的安全上界为 (p_U=0.450341796875\,\mathrm m)，本取值仅高出 (2.03125\times10^{-7}\,\mathrm m)，用于保留安全侧。题面问题4原始螺距为 (1.7\,\mathrm m)，因此本扩展结果未来必须单独标记，不能替代题面原始口径结果。

## 2. 继承与新增

本问继承公共几何模型的把手编号、定长杆约束和单位切向量定义；继承问题1的刚杆约束速度递推；已接收问题4在 (p=0.450342\,\mathrm m) 下的严格2:1边界双圆弧及完整路径碰撞验证。碰撞验证显示该基线存在碰撞，因此本问数值是条件性速度上限。

| 模块 | 继承或新增 | 输入 | 输出 |
|---|---|---|---|
| Q4路径状态 | 继承 | 龙头路径位置、最终分段路径 | (P_i,\boldsymbol\tau_i) |
| 单步速度倍率 | 继承速度公式 | 相邻位置和切向量 | (k_i) |
| 累计速度倍率 | 本问新增汇总 | (k_1,\ldots,k_i) | (K_i) |
| 全局极值搜索 | 本问新增 | 全路径全部 (K_i) | (K_{\max}) |
| 速度上限 | 本问新增 | (K_{\max})、速度上限2 m/s | (v_{\mathrm{head,max}}) |

## 3. 为什么这样建模

固定几何状态下，相邻把手满足

\[
\|P_i-P_{i-1}\|^2=L_i^2.
\]

对时间求导：

\[
(P_i-P_{i-1})\cdot(V_i-V_{i-1})=0.
\]

节点速度沿轨迹切向，令

\[
V_i=w_i\boldsymbol\tau_i,
\]

得到

\[
w_i=w_{i-1}
\frac{(P_i-P_{i-1})\cdot\boldsymbol\tau_{i-1}}
{(P_i-P_{i-1})\cdot\boldsymbol\tau_i}.
\]

定义单步倍率 (k_i) 和累计倍率 (K_i)：

\[
k_i=
\frac{(P_i-P_{i-1})\cdot\boldsymbol\tau_{i-1}}
{(P_i-P_{i-1})\cdot\boldsymbol\tau_i},
\qquad
K_i=\prod_{j=1}^{i}k_j,
\]

则

\[
w_i=K_iw_0,
\qquad
v_i=|K_i|v_{\mathrm{head}}.
\]

因此无需对龙头速度反复二分。只要令龙头单位速度运行一次，得到

\[
K_{\max}=\max_{s,i}|K_i(s)|,
\]

即可计算

\[
v_{\mathrm{head,max}}=\frac{2}{K_{\max}}.
\]

## 4. 完整求解过程

文字流程图：

`接收Q4 p=0.450342路径及碰撞验证 → 沿空间路径粗扫龙头状态 → 连续还原224个把手位置 → 计算各节点单位切向量 → 递推k_i和K_i → 搜索全路径全节点最大倍率 → 对峰值和小分母区局部加密 → 计算2/K_max → 回代全部把手速度 → 独立差分验证`

正式运行时必须同时搜索路径状态和节点编号，不能预设最大速度一定出现在龙尾。轨迹为分段曲线时，应显式检查螺线—圆弧、圆弧—圆弧、圆弧—螺线连接位置。

## 5. 当前结果及其含义

全时段粗扫和连续极值搜索得到 (K_{\max}=1.616147832242)，对应最大恒定龙头速度 (U_{\max}=1.237510554480\,\mathrm{m/s})，建议论文报告为1.238 m/s。回代后全链最大速度为2 m/s，中心差分最大向量误差约为 (6.925\times10^{-7}\,\mathrm{m/s})。

这一数值只回答速度约束。Q4路径首次连续碰撞约在12.829297347 s，故本结果不能表述为无碰撞安全速度。

## 6. 模型检验、局限和下一步接口

正式求解后执行四类验证：

1. 步长收敛：比较至少三档空间步长的 (K_{\max})；
2. 极值加密：对粗扫峰值、连接点和递推分母较小区域做局部连续优化；
3. 独立差分：用相邻空间状态的位置差分验证解析速度倍率；
4. 灵敏度：扰动 Q4 路径参数、节点求根容差和采样步长，检查速度上限是否稳定。

若

\[
|(P_i-P_{i-1})\cdot\boldsymbol\tau_i|
\]

接近零，速度倍率可能出现尖峰，程序必须报告近奇异状态，不能用粗网格掩盖。待接收字段见 `tables/Q5_待接收字段表.md`，验证口径见 `tables/Q5_验证计划.md`。
