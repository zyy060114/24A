# Q2 独立多边形复核

使用 Shapely 2.1.2 将临界候选板对 `(0,8)` 的四角点恢复为独立多边形，未调用 SAT 实现：

| 相对临界时间 | 多边形距离 (m) | 是否相交 | 交集面积 (m²) |
|---:|---:|---|---:|
| (t_* - 10^{-4}) s | 2.63215348396e-06 | 否 | 0 |
| (t_*) | 0 | 是（数值接触） | 1.42981039071e-29 |
| (t_* + 10^{-4}) s | 0 | 是 | 6.93852167004e-12 |

该独立复核与 SAT 裕度从正、到零、再到负的符号变化一致，支持首次临界板对和接触边界口径。
