## 核心结论

- 首次碰撞临界时间：`412.4738376821 s`；
- 首次安全—碰撞粗扫描区间：`[412.0, 412.5] s`；
- 临界全局SAT裕度：`-3.8580e-15 m`，数值上为零；
- 代表性候选板对：代码0-based `(0,8)`，论文1-based `(1,9)`；
- 统一结论：检测到至少一组非相邻板凳达到接触或碰撞临界；
- 全局裕度不保证单调，首次碰撞搜索采用全时域扫描加局部精化。
